# Portal Saúde Brasil

Frontend estático publicado em [portalsaudebr.com](https://portalsaudebr.com/) via GitHub Pages.

O código-fonte completo, incluindo backend Node/Express, tRPC, Drizzle/MySQL, autenticação, painel administrativo, analytics e worker editorial, está no repositório privado [portal-planos-saude-brasil](https://github.com/portalsaudebr/portal-planos-saude-brasil).

> O GitHub Pages hospeda somente o snapshot frontend. Recursos que exigem servidor ou banco permanecem no ambiente full-stack do projeto.
